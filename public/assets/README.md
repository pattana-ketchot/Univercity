# โปรดวางไฟล์รูปภาพของคุณในโฟลเดอร์นี้

## โครงสร้างโฟลเดอร์

```
assets/
├── logo.png              # โลโก้มหาวิทยาลัยสำหรับ Header (ความสูง 56px แนะนำ)
├── hero-building.jpg     # รูปอาคารสำหรับ Hero Section (1200x1000px แนะนำ)
└── courses/              # โลโก้หลักสูตรต่างๆ (200x200px แนะนำ)
    ├── engineering.png   # วิศวกรรมศาสตร์
    ├── business.png      # บริหารธุรกิจ
    ├── computer.png      # วิทยาการคอมพิวเตอร์
    ├── medicine.png      # แพทยศาสตร์
    ├── arts.png          # ศิลปกรรมศาสตร์
    ├── law.png           # นิติศาสตร์
    └── science.png       # วิทยาศาสตร์
```

## ข้อกำหนดไฟล์

### logo.png
- ความสูง: 56px (ความกว้างปรับตามสัดส่วน)
- รูปแบบ: PNG พื้นหลังโปร่งใส
- ตำแหน่ง: มุมซ้ายบนของ Header

### hero-building.jpg
- ขนาด: 1200x1000px ขึ้นไป
- รูปแบบ: JPG หรือ PNG
- เนื้อหา: รูปอาคาร/มหาวิทยาลัย

### courses/*.png
- ขนาด: 200x200px (สี่เหลี่ยมจัตุรัส)
- รูปแบบ: PNG พื้นหลังโปร่งใส
- เนื้อหา: โลโก้คณะ/สาขาวิชา

## หมายเหตุ

หากไม่มีรูปภาพ ระบบจะแสดง Placeholder อัตโนมัติ
